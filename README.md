# Примитивная база данных

## Установка и запуск

Требуются Python 3.12 или новее и менеджер проектов [uv](https://docs.astral.sh/uv/).

В терминале перейдите в корневую папку этого проекта, где находится
`pyproject.toml`, затем выполните:

```bash
uv sync
uv run project
```

Альтернативный запуск:

```bash
uv run python -m primitive_db.main
```

После появления приглашения `Введите команду:` вводите команды базы данных.

## Управление таблицами

| Команда | Действие |
| --- | --- |
| `create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...` | Создать таблицу с указанными столбцами. |
| `list_tables` | Показать имена всех таблиц. |
| `drop_table <имя_таблицы>` | Удалить таблицу из метаданных. |
| `help` | Показать справку по командам. |
| `exit` | Завершить работу программы. |

Поддерживаемые типы столбцов: `int`, `str`, `bool`.
При создании таблицы столбец `ID:int` добавляется автоматически —
в примере ниже его вводить не нужно.

### Пример использования

```text
DB project is running!
***Процесс работы с БД***
Введите команду: create_table users name:str age:int is_active:bool
Таблица users успешно создана со столбцами: ['ID:int', 'name:str', 'age:int', 'is_active:bool']
Введите команду: list_tables
users
Введите команду: drop_table users
Таблица users успешно удалена
Введите команду: exit
```

Создание таблицы с уже существующим именем и удаление несуществующей таблицы
выводят сообщение об ошибке.

## Проверка кода и сборка

Проверка стиля кода:

```bash
uv run ruff check .
```

Сборка пакета и проверка метаданных без публикации:

```bash
uv build
uvx twine check dist/*
```

Собранные файлы `.whl` и `.tar.gz` находятся в папке `dist/`.
